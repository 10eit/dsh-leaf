# 需求覆盖对照（v0.1.0）

对照 [`需求文档.md`](../需求文档.md)（v0.2 需求细化稿）。状态说明：

- ✅ **已实现**：代码、测试或运行中的宿主可验证。
- ◐ **部分实现**：主路径可用，但存在明确缺口或宿主能力边界。
- ○ **未实现**：首版范围外，或依赖尚未提供的宿主扩展点。

> 说明：需求文档本身声明「不包含实现」，其中的优先级、默认行为、布局比例与性能数值是建议基线。本文按这些基线逐项标注当前实现，而不是把建议当成已验收。

| 文件与资源：文件树、基础操作、图片/PDF 预览、导入、自动刷新 | ◐ | 逐层文件树、新建 TeX 文件、在访达中显示、图片/PDF/SVG 预览、稳定写入后自动刷新、隐藏辅助文件开关。未实现：拖入导入、重命名/删除、移动后引用同步。文件树位于写作视图左轨（见 §5.2 说明）。 |

| 编译：主文档、pdfLaTeX/XeLaTeX、完整/快速、错误定位 | ✅ | 编译始终从主文档出发；完整/快速；单构建队列；停止；清理缓存；结构化文件/行错误与日志；旧 PDF 标记。 |

| 模板：最小中英文项目、本地模板目录导入 | ◐ | 内置最小中文（ctex/XeLaTeX）与英文（pdfLaTeX）项目，只增不覆盖。未实现：本地模板目录导入、在线市场。 |
| 性能：按 §11 验证 | ◐ | 已做逐层读取、可见区高亮、轮询去重、单构建、面板未打开不扫描。未做：按 §11 的参考设备/样本做 P95 度量与报告。 |

## 界面与工作区（需求 §5）

| 需求 | 状态 | 说明 |
| --- | --- | --- |
| 工作区右键「启用 dsh-leaf」/「关闭」/保留原生入口 | ✅ | 合并为一个开关「启用/关闭 DSH-leaf 工作台」；启用会置顶改名、创建置顶的持久会话「DSH-leaf 工作台」，关闭恢复名称并归档入口会话，不删文件、不动其他会话。 |
| 全局「默认启用」设置 | ◐ | bundle 配置 `enabledByDefault: true`，单工作区可覆盖为关闭；没有独立的设置页控件（可在插件配置中修改）。 |
| 左侧上方工作区/对话 + 下方文件树 | ◐ | 上方保持宿主原样；**下方文件树受宿主 Slot 限制**：`sidebar.workspaces` 是 single 占位，无法追加面板。文件列改为写作视图内可折叠的一列（位于 Agent 输入条上方，不遮挡对话），宿主右侧「文件」页仍可用。 |
| 新建 TeX 文件入口与快捷键 | ◐ | 文件抽屉内「+」新建文件（文件名/目录/主文档或章节，同名拒绝覆盖）。`⌘D` 未占用（避免静默抢占宿主命令），改用面板按钮与 `⌘⇧L` 打开面板。 |
| 中央区域：点击对话显示原生聊天，点击 `.tex` 进入写作视图 | ◐ | 点击文件在 dsh-leaf 面板内打开；从侧栏可随时回到原生对话。宿主的右侧文件页尚不能把点击路由到 dsh-leaf 面板。 |
| 写作视图布局 55:45、源码/Chat 65:35、可拖拽、按工作区记忆 | ◐ | 单行工具栏 + 文件列（不遮挡输入条）+ 源码 + 底部两行后台 Writing Agent 输入条 + 右侧 PDF/日志双页；宽度持久化。完整聊天记录不在面板内重绘（宿主不允许嵌入 ChatView）。 |
| 资源预览独立标签、不冒充论文 PDF | ✅ | 资源预览在中间区域，论文 PDF 固定在右侧；两者数据源分离。 |

| 独立资源 PDF 不替换论文 PDF | ✅ | 资源 PDF 在中间预览，论文 PDF 固定在右侧。 |

## Writing Agent（需求 §9）

| 需求 | 状态 | 说明 |
| --- | --- | --- |
| 原生模型选择、历史、切换保留 | ✅ | 不新建 runtime；与宿主原生对话一致。 |
| 写作会话上下文（文件/选区/错误） | ◐ | 输入条把当前文件/选区/主文档发给后台生成；「交给 Writing Agent」把同样上下文预填到原生会话；未做附件卡片。 |
| 按任务读取资料、缺数据标待补 | ◐ | 依赖宿主原生 Agent 行为与提示词；插件不额外扫描仓库。 |
| 差异审阅、接受/拒绝/撤销、过期检查 | ◐ | 后台结果提供替换选区/追加/复制，并在写回前检查选区原文是否变化（过期则拒绝）；没有逐行 diff 视图。 |
| 编译修复、停止、最多 3 轮 | ◐ | 错误面板可一键把错误摘要/缺失依赖/日志交给原生 Writing Agent 修复；工具可反复编译。无自动 3 轮计数与停止面板。 |
| 同一会话一次一个任务 | ✅ | 构建按工作区串行；同一面板一次一个构建。 |

## 后续优先事项

1. 接入 PDF→源码反向定位（双击/⌘ 点击）。
2. 文件树右键菜单：相对路径、插入片段、导入图片（同名策略）、重命名/删除。
3. Writing Agent 的差异审阅与选区改写（需要 Conversation/Chat 的 slot 复用能力）。
4. 本地模板目录导入与环境安装引导（下载源、安装位置）。
5. 按需求 §11 建立性能基线与自动测量。
